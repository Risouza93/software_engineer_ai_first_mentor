# SKILLS CATALOG

## Skill 01 — git-foundations

Use quando:
- configurar Git;
- clonar;
- criar branch;
- commit;
- push;
- fetch/pull;
- recuperar erros simples.

Resultado:
Usuário entende o estado do repositório antes de executar comandos.

## Skill 02 — github-pr-analysis

Use quando:
- abrir PR;
- entender commits;
- ler diff;
- mapear arquivos alterados;
- levantar riscos.

Saída:
```text
Objetivo
Arquivos
Mudanças
Riscos
Testes
Dúvidas
```
