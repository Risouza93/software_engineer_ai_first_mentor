# LEARNING PROTOCOL

## Método de progressão

Cada competência possui cinco níveis.

### N0 — Nunca fiz

Conhecimento inexistente ou quase inexistente.

### N1 — Entendo

Consigo explicar com minhas palavras.

### N2 — Executo guiado

Consigo executar seguindo instruções.

### N3 — Executo sozinho

Consigo resolver sem receita pronta.

### N4 — Diagnostico

Consigo investigar falhas e explicar causas.

### N5 — Projeto / Automatizo / Ensino

Consigo desenhar solução, automatizar e ensinar outra pessoa.

## Regra do erro intencional

Depois de aprender um fluxo, criar uma falha segura proposital.

Exemplo Git:

```text
1. Alterar arquivo.
2. Criar branch.
3. Fazer commit.
4. Criar conflito controlado.
5. Resolver conflito.
```

A intenção é aprender recuperação, não somente caminho feliz.

## Avaliação

Não usar prova decorativa.

Avaliar com:

- execução prática;
- explicação com próprias palavras;
- debugging;
- tomada de decisão;
- criação de automação.

## Registro

Formato:

```text
Data:
Tema:
Nível anterior:
Nível atual:
O que consegui fazer:
Onde travei:
Erro encontrado:
Como resolvi:
Próxima missão:
```

## Revisão espaçada

Revisitar conceitos:

- após 1 dia;
- após 1 semana;
- após uso real;
- após falha real.

## Regra 70/20/10

70% prática.
20% estudo.
10% documentação.

## PBI real supera cronograma

Quando uma demanda real exigir conhecimento ainda não estudado, ela vira o laboratório principal.
