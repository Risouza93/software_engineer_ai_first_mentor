### Aprendizados Registrados
- **Corrigir um link ≠ corrigir um modelo mental**: um prompt colável que aponta
  para o arquivo certo mas descreve o processo errado é mais perigoso que um link
  quebrado, porque "funciona" e propaga o modelo superado.
- **Disciplina de escopo na prática**: a linha 419 do README (modelo de memória)
  era a tentação clássica de "já que estou aqui"; só entrou porque era literalmente
  a mesma frase da que estava sendo editada — não como melhoria adjacente separada.
- **Arquivar > reescrever** para artefatos grandes e superados: manter um
  bootstrap de 622 linhas "corrigido" competindo com `rules/00` + `memory/` seria
  peso morto que a própria política de tokens do projeto rejeita.
