# Skill — claude-code-foundations

## Use when
Instalar, configurar, autenticar ou iniciar o uso seguro do Claude Code.

## Pré-requisitos
Validar terminal, Git, PATH e os requisitos atuais da instalação oficial.

## Sequência
ELI5 → validar ambiente → instalar → autenticar → tarefa somente leitura → revisar resultado → alteração controlada → revisar Git diff → executar testes.

## Primeira tarefa
Usar o mesmo repositório do laboratório Codex e executar análise somente leitura.

## Comparação
Comparar Codex e Claude Code usando:
- arquivos consultados;
- precisão factual;
- inferências;
- riscos identificados;
- evidências.

## Definition of Done
O aluno usa Claude Code conscientemente e consegue comparar seu comportamento com Codex.
