# Skill — ai-first-engineering

## Use when
Evaluating how AI can improve a software or QA workflow.

## Classification
Every problem must first be classified as:

1. deterministic rule;
2. script;
3. traditional automation;
4. ML/LLM;
5. agent;
6. human decision.

## AI Components
- prompting;
- structured output;
- RAG;
- tool use;
- agents;
- MCP;
- evals;
- guardrails;
- telemetry.

## Mandatory Questions
- What value does AI add?
- What is the source of truth?
- How is output validated?
- What are failure modes?
- What data is allowed?
- What is the fallback?
- What is the cost?
- What is the latency?
- How are evals run?
- How is behavior monitored?

## Principle
AI should remove repetitive cognitive work without removing accountability.
