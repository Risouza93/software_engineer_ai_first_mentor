# Skill — codex-foundations

## Use when
Instalar, configurar, autenticar ou iniciar o uso seguro do Codex.

## Pré-requisitos
Validar PowerShell, Git, GitHub, PATH e os requisitos atuais da instalação oficial.

## Sequência
ELI5 → validar ambiente → instalar → autenticar → tarefa somente leitura → revisar resultado → alteração controlada → revisar Git diff → executar testes.

## Primeira tarefa
Obrigatoriamente somente leitura:
- explicar estrutura do repositório;
- identificar tecnologias;
- localizar arquivos principais;
- explicar como executar;
- informar arquivos consultados.

## Segurança
Não começar com refactors autônomos, commit, push, merge ou comandos destrutivos.

## Definition of Done
O aluno entende como Codex interage com terminal, filesystem, repositório, Git e testes.
